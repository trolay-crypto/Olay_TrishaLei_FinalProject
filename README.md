# Personal Library Organizer

## Project Overview

Personal Library Organizer is a command-line based Python application that helps users manage their personal book collection. The system allows users to add books, view available books, search for books, borrow books, return books, and monitor the total number of books in the library.

---

## Features

* Add Book
* View Books
* Search Book
* Borrow Book
* Return Book
* Show Total Books
* Save book data using JSON file handling

---

## Technologies Used

* Python
* JSON
